# শুভ জন্মদিন সুরভি 🎂 — মাহফুজের পক্ষ থেকে

সুরভির ২১তম জন্মদিনের (১৪ নভেম্বর ২০২৬) জন্য বানানো একটি ওয়েবসাইট।
সব লেখা বাংলায়, সই — **মাহফুজ (মোঃ মাহফুজ মনির)**।

## এই প্যাকেজে যা যা আছে

| ফাইল | কাজ |
|---|---|
| `index.html` | মূল পেজ — সব সেকশন |
| `style.css` | সব ডিজাইন / অ্যানিমেশন |
| `script.js` | কাউন্টার, হার্ট ক্যানভাস, গ্যালারি, ২৫ কারণ, কেক, চিঠি, গান |
| `assets/surovi-01.jpg` … `assets/surovi-06.jpg` | গ্যালারির ৬টি ছবির জায়গা (এখন সুন্দর placeholder) |
| `README.md` | এই গাইড |

## ভেতরে যা যা আছে (ভিডিওর মতোই)

- **ভূমিকা অ্যানিমেশন:** পেজ লোডে ঝাপসা (blur) থেকে পরিষ্কার হওয়া, হার্ট নিজে নিজে আঁকা হয়
- **হার্ট ক্যানভাস:** প্রজাপতি / কণা দিয়ে parametric heart equation-এ হার্ট তৈরি, ভেতরে “সুরভি”
- **লাইভ কাউন্টার:** ১৪ নভেম্বর ২০০৫ থেকে দিন / ঘণ্টা / মিনিট / সেকেন্ড — প্রতি সেকেন্ডে বাড়ে, বাংলা সংখ্যায়
- **টাইমলাইন:** ২০১৮ → নীরব বছর → ২০২৬-এর শুরু → শেষ ৩–৪ মাস → ১৪ নভেম্বর ২০২৬ প্রথম শুভেচ্ছা
- **গ্যালারি:** ৬ ছবির স্লাইডশো — ফেড অ্যানিমেশন, ডট, ১/৬ কাউন্টার, ক্যাপশন, prev/next, নিজে নিজে বদলায় (৪.৫ সেকেন্ড)
- **২৫ কারণ:** একটা একটা করে র‍্যান্ডমভাবে খোলে, ১/২৫ কাউন্টার, হার্ট-বার্স্ট অ্যানিমেশন
- **কেক:** ৩ মোমবাতি, জ্বলন্ত শিখা — মাইকে ফুঁ দিলে বা ট্যাপ করলে একটা একটা করে নেভে, ধোঁয়া ওঠে, তারপর কনফেত্তি
- **চিঠি:** ইচ্ছে পূরণ হলে খাম খুলে চিঠি বের হয় — [আরেকটা ইচ্ছে করো] ও [স্মৃতিগুলোতে ফিরে যাও] বোতাম
- **গান:** উপরে ডানদিকে 🎵 বোতাম — কোনো অডিও ফাইল লাগে না, নরম সুর বাজে
- **আরও:** ভাসমান বেলুন, প্রজাপতি, তারা, ওঠা হার্ট, স্ক্রল-রিভিল, মোবাইল-বান্ধব

## কম্পিউটারে খুলে দেখা

ZIP খুলে `index.html` ফাইলে ডাবল-ক্লিক করলেই ব্রাউজারে খুলবে — কোনো সার্ভার বা ইনস্টল লাগে না।

> মাইকে ফুঁ দিতে চাইলে `file://` দিয়ে খুললে ব্রাউজার মাইকের অনুমতি নাও দিতে পারে — তখন লাইভ লিংক (GitHub Pages) থেকে খুললে মাইক কাজ করবে। ট্যাপ করে নেভানো সবসময় কাজ করে।

## ছবি বদলানো (আসল ছবি বসানো)

1. সুরভির একার ৬টি ছবি বেছে নাও।
2. নাম বদলে দাও ঠিক এইভাবে: `surovi-01.jpg`, `surovi-02.jpg`, `surovi-03.jpg`, `surovi-04.jpg`, `surovi-05.jpg`, `surovi-06.jpg`
3. `assets` ফোল্ডারের পুরনো ফাইলগুলোর জায়গায় একই নামে বসিয়ে দাও — কোড একদম বদলাতে হবে না।

## GitHub-এ রিপো বানিয়ে লাইভ লিংক পাওয়া (GitHub Pages)

1. [github.com](https://github.com) এ লগইন করো → **+** → **New repository**।
2. নাম দাও: `happy-birthday-surovi` → **Public** রাখো → **Create repository**।
3. **uploading an existing file**-এ ক্লিক করে এই ZIP-এর সব ফাইল আপলোড করো — `index.html`, `style.css`, `script.js`, `README.md` আর `assets` ফোল্ডার (ফোল্ডারসহ)।
4. **Commit changes** চাপো।
5. **Settings** → বামে **Pages** → **Branch:** `main`, **Folder:** `/ (root)` → **Save**।
6. ১–২ মিনিট অপেক্ষা করো — উপরে লিংক দেখাবে, যেমন:
   `https://তোমার-ইউজারনেম.github.io/happy-birthday-surovi/`
7. এই লিংকটাই সুরভিকে পাঠিয়ে দিও।
